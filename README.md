# ATELIER — contemporary women's fashion

Four languages: EN / RU / ES / DE. Includes home, catalogue, product details, size selection, filters, sort, cart drawer, discount demo, checkout demo, FAQ, contact, shipping, returns and legal pages.

Run `python3 -m http.server 8000` and open `http://localhost:8000/en/`. The `_redirects` file makes localized routes work on Netlify/Cloudflare Pages.

Dark/light theme and language preference are stored locally. Product copy is localized. This is a frontend demo: no real payment, stock management, order processing or form delivery is connected.
